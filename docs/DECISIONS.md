# TON ARENA — Decision Log

This file records confirmed decisions separately from proposals. New decisions should be added at the top with a date and a short rationale.

## Confirmed decisions

### 2026-11-06 — One connected ecosystem
**Decision:** TON ARENA, TON ACADEMY, and TON CLUB are product areas in one shared ecosystem, not three independent apps.  
**Reason:** Shared identity, progression, missions, and community foundations reduce duplication and support future growth.

### 2026-11-06 — No gambling or betting
**Decision:** The product will not use gambling or betting mechanics.  
**Reason:** This is an explicit product constraint.

### 2026-11-06 — Free skill-game MVP
**Decision:** The first MVP is BRAIN SPRINT, a free 10-question skill-based game with scoring for accuracy and speed.  
**Reason:** It is a focused way to validate the core experience.

### 2026-11-06 — No initial token issuance
**Decision:** Do not issue a project token at launch.  
**Reason:** Validate real product value before adding token complexity.

### 2026-11-06 — Low-cost, cloud-first workflow
**Decision:** Keep initial costs minimal and do not make the user's old laptop a dependency.  
**Reason:** The project owner has no programming experience and wants to work from an Android phone with cloud tools.

### 2026-11-06 — GitHub repository
**Decision:** Use `daryajj01-hgd/Ton_arena` as the project repository, with `main` as the default branch.  
**Reason:** Central source of truth and version history.

## Proposed technical baseline (not yet final)

- React + TypeScript frontend.
- Node.js + TypeScript backend.
- PostgreSQL database.
- Telegram Mini App as the first distribution channel.
- TON Connect only after the core experience is validated.

These remain proposals until implementation constraints and provider choices are checked.
